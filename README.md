# Iraq Motors

منصة عراقية لبيع وشراء السيارات: إعلانات، معارض وتجار، مقارنة، حاسبة تقسيط، ومستشار سيارات بالذكاء الاصطناعي.

الموقع: https://iraqmotors.site

---

## كيف يعمل الموقع

- موقع ثابت (HTML واحد) يُنشر عبر **GitHub Pages** من فرع `main`.
- البيانات (السيارات، المعارض، المستخدمون) تُحفظ في **Firebase** وتُجلب بالجافاسكربت عند فتح الصفحة.
- مستشار السيارات يعمل عبر **Cloudflare Worker** منفصل يرسل الأسئلة لنموذج Claude.
- الدومين من Namecheap ويشير إلى GitHub Pages.

## الملفات المهمة

| الملف | الوظيفة |
|---|---|
| `index.html` | الموقع الكامل (الصفحة الرئيسية وكل الصفحات). |
| `404.html` | نسخة مطابقة لـ `index.html`. **يجب أن يبقى الملفان متطابقين.** |
| `scripts/update-snapshot.mjs` | سكربت يجلب السيارات من Firebase ويكتب عددها وقائمتها داخل الـ HTML. |
| `.github/workflows/update-snapshot.yml` | يشغّل السكربت تلقائياً كل ساعة. |
| `sw.js` | Service Worker للتخزين المؤقت (تطبيق PWA). |
| `manifest.webmanifest` | إعدادات التطبيق المثبّت على الشاشة الرئيسية. |
| `icons/` | الأيقونات وصورة المشاركة `og-cover.jpg` (1200×630). |
| `CNAME` | اسم الدومين لـ GitHub Pages. |

## لماذا يوجد "Snapshot"؟

السيارات تُحمَّل بالجافاسكربت، فمحركات البحث والذكاء الاصطناعي (جوجل، ChatGPT، Gemini) التي تقرأ الـ HTML الخام ترى صفحة بلا سيارات.
لذلك يكتب السكربت داخل `index.html` و`404.html`:

- عدد السيارات الحقيقي.
- قائمة السيارات بصيغة JSON-LD (بيانات منظمة لجوجل).
- نسخة نصية مخفية بصرياً من القائمة.

### تحذير مهم

لا تحذف ولا تعدّل هذه العلامات داخل `index.html`، فالسكربت يعتمد عليها:

```
<!--SNAPSHOT_HEAD_START--> ... <!--SNAPSHOT_HEAD_END-->
<!--SNAPSHOT_BODY_START--> ... <!--SNAPSHOT_BODY_END-->
```

وكذلك العنصر `<span id="cntCars">`.

## كيف أحدّث الموقع

1. عدّل `index.html` (أو ارفع نسخة جديدة).
2. انسخه كما هو إلى `404.html`.
3. ارفع الملفين (Add file ← Upload files ← Commit changes).
4. من تبويب **Actions** شغّل **Update cars snapshot** يدوياً (Run workflow) حتى تعود قائمة السيارات، لأن الملف المرفوع يكون بعلامات فارغة.
5. انتظر انتهاء **pages build and deployment** ثم افتح الموقع بتبويب خاص (Private) للتأكد.

> ملاحظة: إذا ظهر "Cancelled" على نشر قديم فهذا طبيعي، لأن commit أحدث ألغاه.

## التحديث التلقائي

- يعمل كل ساعة، ويعمل commit فقط إذا تغيّرت السيارات.
- إذا أرجعت قاعدة البيانات صفر سيارات (خطأ مؤقت) فالسكربت لا يكتب فوق النسخة السليمة.
- يحتاج إعداد: **Settings ← Actions ← General ← Workflow permissions ← Read and write permissions**.

## تطبيق الايباد/الموبايل (PWA)

- إذا ظهرت نسخة قديمة في التطبيق المثبّت: احذفه من الشاشة الرئيسية وأضفه من جديد من `https://iraqmotors.site/` (بدون `.html` في الرابط).
- عند تغيير الملفات الكبيرة، غيّر رقم إصدار الكاش داخل `sw.js` (إن وُجد) حتى يتحدّث عند المستخدمين.

## ملفات قديمة

يحتوي الـ repo على نسخ HTML قديمة (مثل `iraq-motors_6.html`). لا تستخدمها ولا تثبّت التطبيق منها.
يُفضّل نقلها لمجلد `archive/` أو حذفها بعد التأكد أنها غير مرتبطة بأي رابط.

## الأمان

- لا تضع كلمات سر أو مفاتيح API أو Tokens في هذا الـ repo (مفتاح Claude يُحفظ فقط كـ Secret داخل Cloudflare).
- قواعد Firebase يجب أن تسمح بقراءة السيارات المعتمدة فقط للزوار، وبالكتابة للمستخدمين المسجلين.
